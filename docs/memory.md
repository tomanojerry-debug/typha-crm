# 记忆与检索

- 最近10轮／20条有效消息作为短期对话窗口，完整Session日志另行保留。
- Workflow与TaskState保留当前任务条件；Run记录每次执行，修改条件、范围或来源后重新验证。
- 个人长期偏好来自本人明确要求或设置，按用户隔离。
- CRM Record保存业务原文、归属、出处与版本。
- Graphiti从有效资料派生实体、关系与变化索引；本机向量帮助按含义找到原文切片。
- ContextPlan按当前任务与授权组织上下文，在模型调用前与提交前复验。

检索结果需要回读当前授权原文，同一Record合并为一份证据。旧原文改版、归档、排除或失权后，不得继续被旧索引、派生笔记或已保存任务结果引用。

公司、联系人和项目范围沿实际来源关联，不通过同名、地区或负责人猜权限。图节点和向量相似度也不会把客户请求升级成订单或公司确认事实。

本地语义索引使用384维多语言MiniLM。Graphiti与本机索引为可选组件；准备步骤见[知识组件](knowledge.md)。
