# 连接网易个人邮箱

Typha 支持 `@163.com`、`@126.com` 和 `@yeah.net`。由工作空间管理员连接需要用于业务的邮箱。连接保存在当前工作空间，归档后的邮件按客户权限提供给成员查看。

## 获取客户端授权码

1. 登录要连接的邮箱，打开「设置 → POP3/SMTP/IMAP」，开启「IMAP/SMTP 服务」。 [网易邮箱网页版](https://email.163.com/)
2. 按提示完成身份验证，复制生成的客户端授权码。如果服务已经开启，在同一页选「新增授权密码」，为 Typha 单独生成一个。 [网易官方授权步骤](https://help.mail.126.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac2a5feb28b66796d3b)

## 在 Typha 中连接

1. 在本机运行的 Typha 中，以管理员账号打开「邮件管理 → 邮箱设置 → 连接邮箱」。填写完整邮箱地址和网易生成的客户端授权码。授权码会加密保存。
2. 点击「连接并同步」。首次同步会分批读取网易允许访问的历史邮件，包括收件箱和可识别的已发送文件夹。查看邮箱卡片上的「已连接」和「最近同步」确认成功。服务运行时，每 5 分钟检查一次，也可以点击「立即同步」。
3. 在邮件管理中查看同步结果。待关联邮件由管理员核对归属。需要让同事使用共享邮箱发信时，在「设置 → 成员与权限 → 邮箱发信授权」授予相应权限。发送还需要客户编辑权限，并由发信人核对确认。

## 授权码失效时

先在网易网页版确认「IMAP/SMTP 服务」已开启，再为同一个邮箱新增授权码。回到 Typha 的「邮箱设置」，在原邮箱卡片选择「更新授权码 → 保存并重试」。更新授权码会沿用该连接已有的同步进度。邮箱若显示「已暂停」，点「恢复同步」后再试。
